# Pushing this to GitHub

The repository is already initialised with full commit history. To publish it:

```bash
# 1. Create an empty repository on github.com (no README, no .gitignore, no licence)

# 2. From inside this folder:
git remote add origin https://github.com/<your-username>/ai4mobility.git
git branch -M main
git push -u origin main
```

If you prefer the GitHub CLI:

```bash
gh repo create ai4mobility --public --source=. --remote=origin --push
```
