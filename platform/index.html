👨‍👩‍👧 For grown-ups

The exercise content here is adapted from published NHS paediatric physiotherapy resources, each linked on its own page. This is a student project and it is not a medical device and not a substitute for your own physiotherapist's advice. If your child has been given a specific programme, follow that one. Stop any exercise that causes pain and seek advice.

Add your own exercise ✏️

Type or paste any exercise description — from a physiotherapy leaflet, a letter, or in your own words — and the splitter will turn it into numbered steps. Your original text is never changed or thrown away, and every step is shown with how confident the splitter is about it.

Whole paragraphs are fine. If you already have numbered steps, they will be kept exactly as you wrote them.

❓ Is this an AI language model?

No. The splitter is a rule-based linguistic engine: it segments sentences, splits them on connecting words like “then” only when both halves read as instructions, classifies each fragment as an action, a position, a hold, a repetition count or a safety note, and pulls out numbers like “hold for 5 seconds” and “repeat 10 times”. It is fully deterministic, runs entirely in your browser, and makes no network requests.

A language model would handle messier, more conversational descriptions better. The code has a defined adapter interface for one, but it is not connected to any model — see the What's real tab for exactly what that would require.

🔜 What we would do next

  1. Connect a language model to the splitter. Needs a server-side proxy holding the API key, a schema-constrained prompt, validation of the returned JSON, and the rule-based splitter kept as the fallback. The safety question — a model inventing an instruction that was not in the source — is why the original description is already displayed beside the steps.
  2. Live pose feedback. Run landmark detection on-device, compare joint angles against the target pose for the current step, and give a simple “try lifting a bit higher” prompt. Requires camera consent handling and an ethics amendment before any child uses it.
  3. Save progress. A small backend with accounts so a child's history persists and a physiotherapist can see adherence between appointments.
  4. Evaluate with real families. Nothing here has been tested with a child or a clinician. That is the largest gap in the whole project.
